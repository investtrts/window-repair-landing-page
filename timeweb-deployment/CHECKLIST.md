# ✅ Чек-лист размещения сайта на Timeweb

Используйте этот чек-лист, чтобы убедиться, что все сделано правильно.

## 📋 Подготовка (до начала работ)

- [ ] Заказан хостинг на Timeweb
- [ ] Получены доступы к панели управления
- [ ] Получены доступы FTP (host, login, password)
- [ ] Получены доступы MySQL (host, database, username, password)
- [ ] Домен настроен (или используется технический домен Timeweb)

## 🗄️ Настройка базы данных MySQL

- [ ] Открыт phpMyAdmin через панель Timeweb
- [ ] Выбрана нужная база данных
- [ ] Выполнен SQL скрипт `mysql-schema.sql` (создание таблиц)
- [ ] Выполнен SQL скрипт `mysql-seed-data.sql` (заполнение данными)
- [ ] Проверено наличие данных в таблицах:
  - [ ] `services` - 6 записей
  - [ ] `benefits` - 8 записей
  - [ ] `gallery_items` - 6 записей
  - [ ] `reviews` - 9 записей
  - [ ] `leads` - таблица пустая (заполнится заявками)

## 📁 Загрузка файлов Frontend

- [ ] Собран проект командой `npm run build`
- [ ] Подключен FTP-клиент к хостингу
- [ ] Загружены ВСЕ файлы из папки `dist/` в `public_html/`
- [ ] Проверена структура (index.html в корне `public_html/`)
- [ ] Загружен файл `.htaccess` в корень `public_html/`
- [ ] Проверены права на файлы (должны быть 644)

## 🔧 Загрузка Backend (PHP API)

- [ ] Создана папка `api/` в `public_html/`
- [ ] Загружены все PHP файлы из `timeweb-deployment/backend-php/`:
  - [ ] `config.php`
  - [ ] `content.php`
  - [ ] `reviews.php`
  - [ ] `submit-lead.php`
  - [ ] `.htaccess`
- [ ] Проверены права на файлы (должны быть 644)

## ⚙️ Настройка конфигурации

- [ ] Открыт файл `public_html/api/config.php`
- [ ] Обновлены параметры подключения к MySQL:
  - [ ] `DB_HOST` (обычно `localhost`)
  - [ ] `DB_NAME` (имя базы из панели)
  - [ ] `DB_USER` (пользователь из панели)
  - [ ] `DB_PASS` (пароль из панели)
- [ ] Сохранены изменения

## 🔗 Обновление URL в коде

- [ ] Открыт файл `src/pages/Index.tsx` локально
- [ ] Изменены константы API:
  ```typescript
  const CONTENT_API = 'https://вашдомен.ru/api/content.php';
  const REVIEWS_API = 'https://вашдомен.ru/api/reviews.php';
  ```
- [ ] Обновлены обработчики форм `handleSubmit` и `handlePopupSubmit`
- [ ] Проект пересобран командой `npm run build`
- [ ] Обновленные файлы из `dist/` загружены на хостинг

## 🧪 Тестирование API
