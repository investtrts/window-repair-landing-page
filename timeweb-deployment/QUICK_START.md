# 🚀 Быстрый старт - Размещение на Timeweb

## За 5 минут запустите сайт на Timeweb!

### Шаг 1: Настройка MySQL (2 минуты)

1. Откройте phpMyAdmin в панели Timeweb
2. Выберите вашу базу данных
3. Вкладка "SQL" → Скопируйте файл `mysql-schema.sql` → Выполнить
4. Снова "SQL" → Скопируйте файл `mysql-seed-data.sql` → Выполнить

✅ База данных готова!

### Шаг 2: Загрузка файлов (2 минуты)

#### Вариант A: Через FTP (FileZilla, WinSCP)
```
Подключение:
- Host: ftp.вашдомен.ru
- User: ваш_логин
- Pass: ваш_пароль

Загрузить в public_html/:
- Все файлы из папки dist/
- .htaccess (из timeweb-deployment/)

Создать папку api/ и загрузить:
- Все файлы из timeweb-deployment/backend-php/
```

#### Вариант B: Через файловый менеджер Timeweb
1. Панель управления → Файловый менеджер
2. Загрузите файлы из `dist/` в `public_html/`
3. Создайте папку `api/`
4. Загрузите PHP файлы в `api/`

### Шаг 3: Настройка Backend (1 минута)

Откройте файл `public_html/api/config.php` и замените:

```php
define('DB_NAME', 'ваше_имя_базы');  // из панели Timeweb
define('DB_USER', 'ваш_юзер');       // из панели Timeweb
define('DB_PASS', 'ваш_пароль');     // из панели Timeweb
```

Где взять эти данные?
→ Панель Timeweb → Базы данных → MySQL → Смотрите креды

### Шаг 4: Проверка

Откройте в браузере:
- ✅ https://вашдомен.ru - должен открыться сайт
- ✅ https://вашдомен.ru/api/content.php?type=services - должен вернуть JSON
- ✅ https://вашдомен.ru/api/reviews.php - должен вернуть JSON

Если все работает - **готово!** 🎉

## Частые проблемы

### Проблема: Сайт не открывается (404)
**Решение:** Проверьте, что файлы из `dist/` загружены в `public_html/`, а не в подпапку

### Проблема: API возвращает ошибку подключения
**Решение:** Проверьте креды в `config.php` - они должны совпадать с панелью Timeweb

### Проблема: Сайт показывает пустые данные
**Решение:** Проверьте, что выполнили `mysql-seed-data.sql` в phpMyAdmin
