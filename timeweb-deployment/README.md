# 📦 Пакет для размещения на Timeweb с MySQL

Этот пакет содержит все необходимое для размещения вашего сайта на хостинге Timeweb с базой данных MySQL.

## 📁 Содержимое пакета

```
timeweb-deployment/
├── README.md                    # Это файл - обзор пакета
├── QUICK_START.md              # ⚡ Быстрый старт за 5 минут
├── DEPLOYMENT_GUIDE.md         # 📖 Полная пошаговая инструкция
├── UPDATE_API_URLS.md          # 🔗 Как обновить URL API в коде
├── CHECKLIST.md                # ✅ Чек-лист для проверки
│
├── mysql-schema.sql            # 🗄️ SQL скрипт создания таблиц
├── mysql-seed-data.sql         # 📊 SQL скрипт с тестовыми данными
│
├── .htaccess                   # ⚙️ Конфигурация для SPA
│
└── backend-php/                # 🔧 Backend API на PHP
    ├── config.php              # Настройки подключения к MySQL
    ├── content.php             # API для услуг/преимуществ/галереи
    ├── reviews.php             # API для отзывов
    ├── submit-lead.php         # API для приема заявок
    └── .htaccess               # Защита конфиг-файлов
```

## 🚀 С чего начать?

### Вариант 1: Быстрый старт (для опытных)
Откройте **QUICK_START.md** - там инструкция на 5 минут.

### Вариант 2: Подробная инструкция (для новичков)
Откройте **DEPLOYMENT_GUIDE.md** - там все расписано пошагово с скриншотами.

### Вариант 3: Чек-лист (для проверки)
Откройте **CHECKLIST.md** - отмечайте галочками выполненные пункты.

## 🆘 Частые проблемы

### Проблема: 500 Internal Server Error
**Файл:** backend-php/config.php  
**Причина:** Неверные креды MySQL  
**Решение:** Проверьте DB_NAME, DB_USER, DB_PASS

### Проблема: Пустой экран
**Файл:** .htaccess  
**Причина:** Неправильный .htaccess  
**Решение:** Используйте .htaccess из этого пакета

### Проблема: API возвращает пустой массив
**Файл:** mysql-seed-data.sql  
**Причина:** Данные не загружены в БД  
**Решение:** Выполните скрипт в phpMyAdmin

### Проблема: CORS ошибки
**Файл:** backend-php/*.php  
**Причина:** Не установлены CORS заголовки  
**Решение:** Проверьте, что используете файлы из этого пакета

## 🔗 Структура на хостинге

После размещения должна получиться такая структура:

```
public_html/
├── index.html              # Главная страница
├── .htaccess               # Конфигурация SPA
├── assets/                 # JS, CSS, изображения
│   ├── index-[hash].js
│   ├── index-[hash].css
│   └── ...
└── api/                    # Backend API
    ├── config.php          # С вашими кредами!
    ├── content.php
    ├── reviews.php
    ├── submit-lead.php
    └── .htaccess
```

   https://вашдомен.ru → должна открыться главная страница

2. **API возвращает данные:**

3. **Формы работают:**
